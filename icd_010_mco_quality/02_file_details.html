File Details

MCO Quality Patient-Level Data (PLD) contains one row per member per plan. Members may appear in multiple plans but will not appear more than once per plan-year. Not all data is audited; historical challenges in file creation mean results should be interpreted with caution.

Each PLD dataset includes the following components:

  • Text file (.txt)
  • SAS file (.sas7bdat)
  • Data dictionary (Excel, .xlsx)

Files are UTF-8 encoded and delivered as compressed .zip archives.
